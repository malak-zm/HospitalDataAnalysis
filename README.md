\# Hospital Data Analysis



Mini-project to manipulate patient data and visualize basic statistics using Python, pandas and matplotlib.



\## Structure



\- `data/` : CSV files (patients.csv)

\- `notebooks/` : Jupyter notebooks (patients\_analysis.ipynb)

\- `scripts/` : optional Python scripts

\- `env/` : virtual environment (ignored by Git)



\## How to run



1\. Activate the environment

2\. Install the dependencies: `pip install -r requirements.txt`

3\. Launch Jupyter: `python -m notebook`

4\. Open `notebooks/patients\_analysis.ipynb`
